# MAYEN Leather Website

A responsive website for **MAYEN Leather** — luxury handcrafted leather belts manufacturer and international private-label exporter.

## ✨ Features
- **Artisan Showcase**: Interactive product catalog across Formal, Casual, Braided, Designer, and Men's Belts with filtering and specs.
- **Craftsmanship & Manufacturing**: Detailed factory process walkthrough from full-grain hide selection, precision vegetable tanning, edge beveling to solid brass hardware assembly.
- **Quality Standards**: Strict international ASTM/ISO testing guidelines, sustainable sourcing, and warranty highlights.
- **Request a Quote**: Comprehensive interactive inquiry form with real-time validation for bulk, retail, and bespoke private-label orders.
- **WhatsApp Direct Connect**: Floating one-tap quick inquiry button for instantaneous B2B conversations.
- **Visual Gallery**: High-definition grid showcasing craftsmanship, raw materials, stitch work, and buckle finishes.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone <repo-url>

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## 🛠 Tech Stack
- **Framework**: React 18
- **Bundler**: Vite
- **Styling**: Tailwind CSS with custom luxury leather theme
- **Icons**: Lucide Icons
- **Typography**: Playfair Display & Plus Jakarta Sans
